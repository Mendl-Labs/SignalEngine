# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SignalEngine, please report it privately through
GitHub Security Advisories rather than opening a public issue:

https://github.com/Mendl-Labs/SignalEngine/security/advisories/new

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull
requests, and please do not email a personal address — the advisory form above is the only
supported reporting channel.

We will acknowledge your report and work with you to understand and address the issue before any
public disclosure.
